\chapter{Introducción}

\section{Propósito}
El propósito de este documento es especificar los requisitos de software (ERS) para el Sistema de Gestión de Ejemplo. Este documento describe la funcionalidad, rendimiento, y restricciones del sistema.

\section{Alcance}
El sistema permitirá a los usuarios gestionar sus tareas diarias de forma eficiente, integrando notificaciones y reportes automáticos.

\section{Uso de Inteligencia Artificial}
